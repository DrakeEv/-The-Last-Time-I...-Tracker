# Activity Timer

A simple, self-contained timer app to track when you last did something. Perfect for "last watered the grass," "last checked the mailbox," or any recurring task.

## Features

- **Track multiple activities** — add as many timers as you need
- **Survives computer restarts** — data persists via browser storage
- **No internet required** — completely offline, works anywhere
- **Delete timers anytime** — remove any timer with one click
- **Light/dark mode** — automatically adapts to your system preference
- **Single HTML file** — just download and open in your browser

## How to use

1. **Download** `activity-timer.html`
2. **Open** it in your web browser (double-click the file)
3. **Type** what you did (e.g., "watered the grass")
4. **Click** "Add timer" (or press Enter)
5. **Watch** it count up the elapsed time
6. **Delete** any timer by clicking the ✕ button

That's it! Your timers are automatically saved and will still be there if you close and reopen the app, even after restarting your computer.

## Features in detail

- **Elapsed time display** — Shows days, hours, minutes, or seconds depending on how long it's been
- **Timestamp** — Each timer shows the exact date and time you created it
- **Persistent storage** — Uses browser localStorage (private to your device)
- **Real-time updates** — Timers update every second
- **Empty state** — Shows a friendly message when you have no timers yet

## Requirements

- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No installation needed
- No internet connection required
